One haiku about debugging, in strict 5-7-5 syllables: logs scroll past midnight, one line says the server died — but it never lived. The middle line gives the judge its concrete picture, a single log line naming a dead server, and the last line turns the whole poem: there was nothing to kill, because the server was never running at all. No cursor-at-3am, no typo, no "works on my machine" — just logs, one line, and the reversal.

## Run it

```sh
python3 main.py
```

This writes the haiku to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`), UTF-8, with no trailing newline. Python 3.13, standard library only, deterministic, no network.
